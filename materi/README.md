# Materi untuk peserta

Pilih `.ipynb` untuk membuka lembar kerja. Setiap notebook berisi penjelasan,
kode, dan hasil yang dapat dibaca. Berkas `.py` dengan nama yang sama dipakai
pengajar untuk menyunting sumber.

Setiap dataset diawali tabel **Kenali data** yang menjelaskan kolom, satuan,
kode kategori, dan perannya dalam model. Baca tabel ini sebelum melihat data
atau menafsirkan koefisien. [Kamus seluruh variabel](../panduan/07_kamus_variabel.md)
dapat dipakai untuk mencari singkatan yang belum dikenal.

| Folder | Cara mengikuti |
|---|---|
| [01_ekonometrika/](01_ekonometrika/README.md) | Mulai dari `00_persiapan_colab.ipynb`, kemudian ikuti contoh 01 sampai 06. |
| [02_latihan/](02_latihan/README.md) | Kerjakan latihan setelah mempelajari contoh dengan nomor yang sama. |
| [03_regresi_housing/](03_regresi_housing/README.md) | Praktik regresi dari membaca data sampai menilai prediksi, mengikuti slide. |
| [04_dashboard_indonesia/](04_dashboard_indonesia/README.md) | Penutup: ubah analisis menjadi dashboard interaktif dari notebook, tanpa terminal. |

Tautan **Buka di Colab** untuk setiap notebook tersedia pada
[daftar materi](../panduan/00_daftar_materi.md). Jalankan sel dari atas dengan
**Shift + Enter** dan koneksi internet. Sel `URL_DATA` menentukan alamat CSV di GitHub.
[Lihat data yang dipakai tiap notebook](../panduan/08_peta_pemakaian_data.md).

Jika baru pertama memakai notebook, baca [panduan pemula](../panduan/01_panduan_pemula.md).
