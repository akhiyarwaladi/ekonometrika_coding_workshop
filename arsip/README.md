# Arsip penataan

Cadangan dan berkas kerja di sini disimpan lokal untuk penelusuran riwayat;
isinya tidak diunggah ke GitHub. Materi aktif berada di
[materi/](../materi/) dan alat yang digunakan saat ini berada di [alat_bantu/](../alat_bantu/README.md).

- `cadangan_sebelum_penataan.zip`: salinan lengkap berkas aktif sebelum penataan.
- `cadangan_sebelum_scikit_learn.zip`: materi sebelum penyeragaman estimator scikit-learn.
- `notebook_regresi_housing_asli.ipynb`: notebook Housing awal sebelum penyederhanaan.
- `rencana_penataan.json`: pasangan lokasi lama dan lokasi baru.
- `slide/png_regresi_300_dpi/`: 31 PNG ekspor lama berukuran 3000 × 1688 piksel.
- `berkas_kerja/`: pratinjau dan skrip pengerjaan lama, termasuk migrasi sekali jalan.
  Skrip migrasi menyimpan jalur historis dan tidak dipakai ulang untuk tutorial.

Untuk mencari nama lama, buka [peta perubahan nama](../laporan/peta_perubahan_nama.csv).
