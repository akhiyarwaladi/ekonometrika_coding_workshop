# PNG untuk mengajar: versi tajam

Gunakan `halaman_01.png` sampai `halaman_31.png` untuk mengajar.
Seluruh gambar berukuran **6000 × 3375 piksel (6K), dengan metadata 600 dpi**.
Logo, header, dan footer berwarna tetap ditutup putih.

Untuk mengambil seluruh gambar sekaligus, gunakan
[ZIP berisi 31 PNG](../../alat_bantu/paket/png_regresi_tajam.zip).

Blok kode halaman 20, 21, 24, 25, 27, dan 28 dibangun dari teks vektor.
Tabel halaman 19, 21, dan 24 serta beberapa rumus juga dibangun ulang.
Contoh metrik halaman 27–28 mengikuti notebook Housing yang sudah diuji.

| Contoh yang dicari | Gambar |
|---|---|
| Membagi data latih dan uji | [halaman_20.png](halaman_20.png) |
| Melatih regresi linear | [halaman_21.png](halaman_21.png) |
| Memeriksa VIF | [halaman_24.png](halaman_24.png) |
| Melihat korelasi | [halaman_25.png](halaman_25.png) |
| Menghitung R² | [halaman_27.png](halaman_27.png) |
| Menghitung RMSE | [halaman_28.png](halaman_28.png) |

Untuk menjalankan kode saat praktik, buka
[notebook Housing](../../materi/03_regresi_housing/01_regresi_housing.ipynb).
Lihat [catatan perbaikan](../../alat_bantu/laporan/ketajaman_slide.md) untuk perubahan rinci.
Ekspor lama 300 dpi disimpan lokal di `alat_bantu/arsip/slide/png_regresi_300_dpi/`.
