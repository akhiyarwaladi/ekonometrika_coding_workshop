# PNG regresi versi tajam

Gunakan `halaman_01.png` sampai `halaman_31.png` untuk mengajar.
Seluruh gambar berukuran **6000 × 3375 piksel (6K), dengan metadata 600 dpi**.
Logo, header, dan footer berwarna tetap ditutup putih.

Untuk mengambil seluruh gambar sekaligus, gunakan
[ZIP berisi 31 PNG](../../paket/png_regresi_tajam.zip).

Blok kode halaman 20, 21, 24, 25, 27, dan 28 dibangun dari teks vektor.
Tabel halaman 19, 21, dan 24 serta beberapa rumus juga dibangun ulang.
Contoh metrik halaman 27–28 mengikuti notebook Housing yang sudah diuji.

Untuk memperbesar lebih jauh, gunakan [PDF versi tajam](../03_regresi_machine_learning_tajam.pdf).
Lihat [catatan perbaikan](../../laporan/ketajaman_slide.md) untuk perubahan rinci.
Ekspor sebelumnya tetap ada di [png_regresi/](../png_regresi/).
