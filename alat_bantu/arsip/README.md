# Arsip lokal

Cadangan sebelum penataan dan berkas pengerjaan lama disimpan di sini.
Arsip tidak diunggah ke GitHub dan tidak dipakai untuk mengikuti tutorial.
Notebook dashboard yang digunakan sekarang hanya
`materi/04_dashboard_indonesia/01_dashboard_ekonomi.ipynb`.

- `cadangan_sebelum_penyederhanaan.zip`: cadangan terverifikasi sebelum penyederhanaan folder.
- `dashboard_ngrok_sebelumnya/`: duplikat notebook dashboard lama, disimpan untuk pemulihan.
- `panduan_lama/`: petunjuk lama yang sudah digantikan README utama.
- `cadangan_sebelum_penataan.zip`: cadangan awal berkas dan data.
- `berkas_kerja/`: hasil pengerjaan serta skrip migrasi sekali jalan.
